# yaniv-efraim-kb

Yaniv Efraim's personal Hebrew-language knowledge base — a static HTML site, no build step or dependencies.

## Run locally

```
node tools/dev-server.js
```

Then open http://localhost:5173.

## Deploy

Push to `master`. GitHub Pages serves the site directly from the `master` branch root at https://yefraim85.github.io/yaniv-efraim-kb/.
